# تِك بوكس — متجر إلكتروني عربي مع نظام مكافآت ذكي

متجر إلكتروني عربي تجريبي (MVP) للإكسسوارات التقنية مبني بـ **Next.js** و **Tailwind CSS**،
يحل مشكلة "السلة بمنتج واحد" عبر نظام مكافآت محفّز يرفع متوسط قيمة الطلب.

## الفكرة

عندما يضيف العميل منتجاً واحداً فقط، يظهر له:
> "أضف منتجاً آخر وأكمل 160 ر.س لفتح صندوقك الغامض 🎁"

عندما يقترب من 160 ر.س، يظهر:
> "أضف 40 ر.س لفتح الشحن المجاني 🚚"

عند تحقق الشرطين (منتجين + 160 ر.س):
- يُفعَّل الشحن المجاني تلقائياً
- يُفتح الصندوق الغامض بأنيميشن احتفالي
- يُضاف الصندوق إلى السلة تلقائياً

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## النشر على Vercel

```bash
vercel
```

أو اربط المستودع بحساب Vercel — لا حاجة لأي متغيرات بيئة.

## التقنيات

- **Next.js 14** (App Router)
- **React 18**
- **Tailwind CSS 3**
- **Framer Motion** للأنيميشن
- **canvas-confetti** للحظة فتح المكافأة

## بنية المشروع

```
app/          صفحات الموقع
components/   مكونات الواجهة
context/      حالة السلة العامة
lib/          بيانات المنتجات ومنطق المكافآت
```
